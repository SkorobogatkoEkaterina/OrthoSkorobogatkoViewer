# Сетапы

**Просмотр и анализ планов лечения на элайнерах из Maestro 3D**

Приложение для Windows и macOS · работает в браузере · всё считается на вашем компьютере

Автор — **Екатерина Скоробогатько** · [@katya_skorobogatko](https://www.instagram.com/katya_skorobogatko/) · [orthoskorobogatko.ru](https://orthoskorobogatko.ru)

## О проекте

«Сетапы» — инструмент ортодонта для работы с планом лечения на элайнерах. Программа открывает экспорт трансформационных моделей из **Maestro 3D**, показывает перемещения зубов по шагам, совмещает план с КЛКТ и контрольными сканами, помогает спланировать вспомогательные элементы и готовит понятный файл для пациента.

Файлы пациентов **никуда не отправляются**: модели, КЛКТ и сканы обрабатываются прямо на компьютере врача.

## Возможности

### План лечения
- Загрузка ZIP-архивов верхней и нижней челюсти из Maestro 3D (ZIP-PLY / OBJ с Deep Export)
- 3D-просмотр по шагам с плавной анимацией, ракурсы «спереди / справа / слева / окклюзионные»
- Десна, аттачменты, номера зубов по FDI, исходное положение поверх текущего шага
- **Таблица перемещений** по осям зуба: экструзия/интрузия, вестибуло-оральное и мезио-дистальное смещение, ротация, ангуляция, торк — с начала лечения и за каждый шаг
- **Сложные движения**: подсветка зубов по типу и сложности перемещения с учётом биомеханики, предсказуемости и скелетной опоры

### Контакты и сепарация
- **Окклюзионные контакты** между челюстями с настраиваемым порогом
- **Апроксимальные контакты** между соседними зубами: контакт, тугой контакт, щель, перекрытие
- **Автоматическая сепарация**: расчёт IPR по всем шагам плана, сверка с Maestro, печатная карта сепарации

### КЛКТ
- Кость и сегментированные зубы с корнями (STL), **автоматическое совмещение** с моделями без постановки точек
- Корни двигаются вместе с зубами по шагам плана, кость остаётся неподвижной

### Вспомогательные элементы
- **Минивинты** (6×1,5 … 17×2 мм), **кнопки**, **вырезки**: перемещение мышкой, наклон, погружение
- Контроль расстояния от минивинта до корней на всех шагах лечения
- **Эластики** до 6 точек (прямые, треугольные, коробочные) с подбором размера и силы по растяжению ×3
- **Эластические цепочки** с расчётом звеньев и активацией на одно звено
- Эластики и цепочки огибают коронки и аттачменты, длина считается по реальному ходу

### Контроль лечения
- Наложение нового скана пациента на любой шаг плана с автоматическим совмещением
- Карта отклонений на зубах и таблица: насколько зуб отстаёт от плана и какая доля движения реализована

### Для пациента
- **Экспорт в один HTML-файл**: для пациента (только просмотр) или для врача (с продолжением редактирования)
- Облегчённый режим для телефона
- **Публикация ссылкой** на собственный сайт врача: пациент открывает план в браузере на любом телефоне

> **Первый запуск.** Приложение не подписано платным сертификатом разработчика, поэтому система предупредит:
> - **Windows:** «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».
> - **macOS:** правый клик по приложению → «Открыть» → «Открыть». Если появляется сообщение «приложение повреждено»:
>   ```bash
>   xattr -cr /Applications/Сетапы.app
>   ```

### Как веб-приложение

Если просмотрщик размещён на сайте, откройте его в Chrome или Edge и нажмите **«Установить приложение»**. Программа появится в меню «Пуск» или в Launchpad, будет открываться в отдельном окне и работать без интернета.

## Как пользоваться

1. В Maestro 3D экспортируйте отдельно модели **ВЧ** и **НЧ** в формате **ZIP-PLY** с включённым **Deep Export**.
2. Откройте «Сетапы» и перетащите архивы в окно. По желанию добавьте КЛКТ (кость и зубы, STL), ФИО пациента, врача и комментарий.
3. Нажмите **«Открыть план лечения»**.
4. Расставьте элементы и проверьте контакты и сепарацию во вкладке **«Анализ»**.
5. **«Экспорт»**: сохраните файл для пациента или для себя, чтобы продолжить позже. Сохранённый план открывается через меню **Файл → Открыть сохранённый план** (Ctrl+O).

| Сочетание клавиш | Действие |
|---|---|
| Ctrl/⌘ + N | Новый кейс |
| Ctrl/⌘ + O | Открыть сохранённый план |
| Ctrl/⌘ + E | Экспорт |
| Пробел | Воспроизведение / пауза |
| ← → | Предыдущий / следующий шаг |
| Delete | Удалить выбранный элемент |
| Esc | Отменить действие |

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start            # запустить приложение
npm run dist:win     # собрать установщик Windows (на Windows)
npm run dist:mac     # собрать установщик macOS (на Mac)
```

При каждой загрузке изменений в репозиторий GitHub Actions автоматически собирает установщики для обеих систем и выкладывает их в [Releases](https://github.com/SkorobogatkoEkaterina/OrthoSkorobogatkoViewer/releases) (`.github/workflows/main.yml`). Ссылки «Скачать» всегда ведут на последнюю версию.

### Обновление версии

1. Замените `app/index.html` на новую версию просмотрщика.
2. Увеличьте `"version"` в `package.json`, например `1.0.0` → `1.0.1`.
3. Загрузите изменения: через ~10 минут новая версия появится в **Releases**, ссылки «Скачать» обновятся сами.

## Технологии

- Собственный 3D-движок на **WebGL**, без внешних библиотек
- Чтение ZIP, PLY, OBJ, STL и XML Maestro прямо в браузере
- Совмещение моделей по поверхности (ICP) для КЛКТ и контрольных сканов
- **Electron** — настольное приложение для Windows и macOS
- PWA — установка из браузера и работа без сети

## Конфиденциальность

- Все вычисления выполняются локально, на компьютере врача.
- Программа не собирает статистику и не обращается к внешним серверам.
- Данные покидают компьютер только тогда, когда врач сам нажимает «Опубликовать ссылкой»: план загружается на его собственный сайт.
