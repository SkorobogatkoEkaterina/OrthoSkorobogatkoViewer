СЕТАПЫ — НАСТОЛЬНОЕ ПРИЛОЖЕНИЕ ДЛЯ WINDOWS И MAC
Автор — Екатерина Скоробогатько, @katya_skorobogatko

Эта папка — проект приложения. Установщики (.exe для Windows и .dmg для Mac) собираются
бесплатно на GitHub, ничего ставить на компьютер не нужно.

Как получить установщики (один раз, ~15 минут)
  1. Зарегистрируйтесь на github.com (бесплатно).
  2. Нажмите «+» → «New repository». Имя, например, setups-app. Выберите Private. Create.
  3. На странице репозитория: «uploading an existing file» → перетащите ВСЁ содержимое этой
     папки (main.js, package.json, папки app, build, .github и т. д.) → «Commit changes».
     Важно: папка .github скрытая — если её не видно, включите показ скрытых файлов
     (Windows: Проводник → Вид → Скрытые элементы; Mac: Cmd+Shift+точка).
  4. Откройте вкладку «Actions» — там сама запустится «Сборка приложения» (~10 минут).
  5. Когда появится зелёная галочка, откройте сборку → внизу «Artifacts»:
       Сетапы-Windows — внутри Setups-1.0.0-win-x64.exe
       Сетапы-macOS   — внутри Setups-1.0.0-mac-universal.dmg (Intel и Apple M1–M4)

Установка
  Windows: запустите .exe. Если появится синее окно «Windows защитила компьютер» —
    «Подробнее» → «Выполнить в любом случае». Ярлык «Сетапы» появится на рабочем столе и в «Пуске».
  Mac: откройте .dmg и перетащите «Сетапы» в «Программы». При первом запуске:
    правый клик по приложению → «Открыть» → «Открыть».
    Если macOS пишет «приложение повреждено», выполните в Терминале:
      xattr -cr /Applications/Сетапы.app
  Предупреждения появляются, потому что приложение не подписано платным сертификатом
  разработчика (Windows ~ от 15 тыс. ₽/год, Apple — 99 $/год). На работу это не влияет.

Как обновлять
  Когда я пришлю новую версию просмотрщика, замените файл app/index.html в репозитории
  (Add file → Upload files) и поменяйте "version" в package.json, например 1.0.1.
  GitHub соберёт новые установщики сам.

Что умеет приложение
  Всё, что просмотрщик: модели Maestro, КЛКТ, элементы, эластики, сепарация, контроль, экспорт,
  публикация ссылкой на сайт. Меню «Файл»: Новый кейс (Ctrl+N), Открыть сохранённый план (Ctrl+O),
  Экспорт (Ctrl+E). Всё считается на компьютере, файлы пациентов никуда не отправляются.
